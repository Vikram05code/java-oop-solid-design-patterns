# Java OOP, SOLID Principles & Design Patterns

A hands-on Java repository where I’m learning and practicing:

- Object-Oriented Programming (OOP)
- SOLID Principles
- Design Patterns
- Clean Code
- Low Level Design (LLD)

through practical examples, refactoring exercises, and real-world backend design problems.

The goal of this repository is not just to learn theory, but to understand how experienced developers actually think while designing scalable and maintainable systems.

---

# Why This Repository?

While working on backend applications and preparing for interviews, I realized that writing working code is only one part of software engineering.

Designing clean, extensible, and maintainable systems is equally important.

This repository is my learning journey to improve:
- object-oriented thinking
- clean coding practices
- design skills
- problem-solving ability
- backend engineering fundamentals

# Learning Approach

Most modules in this repository may include:

- Problem Statement
- Initial/Bad Design
- Refactored Design
- Code Examples
- Explanations
- Notes
- UML Diagrams

The idea is to understand:
- why bad design happens
- how to identify design issues
- how to refactor code properly
- when to use design patterns
- how scalable systems are structured

# Real-world Pattern Examples

| Problem | Design Pattern |
|---|---|
| Multiple payment methods | Strategy Pattern |
| Notification subscriptions | Observer Pattern |
| Request processing pipeline | Chain of Responsibility |
| Complex object creation | Builder Pattern |
| Third-party API integration | Adapter Pattern |
